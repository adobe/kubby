Navigation ​

Learn how to navigate Kubby efficiently using keyboard shortcuts and UI elements.

Navigation Model ​

Kubby uses a hierarchical navigation model:

Context → Namespace → Resource Type → Resource → Detail/Logs/Shell

You can navigate forward by drilling into resources, and backward using Esc.

Global Navigation ​

These controls are available from anywhere in the app:

Context Selector (Opt+C) ​

Switch between Kubernetes contexts (clusters):

  1. Press Opt+C to open the context selector
  2. Type to filter available contexts
  3. Press Enter to select
  4. The view refreshes with the new context

Namespace Selector (Opt+N) ​

Switch namespaces within the current context:

  1. Press Opt+N to open the namespace selector
  2. Type to filter namespaces
  3. Select "All Namespaces" to view across all namespaces
  4. Press Enter to select

Resource Type Selector (Opt+R) ​

Switch to a different resource type:

  1. Press Opt+R to open the resource type selector
  2. Type to filter (e.g., "deploy", "pod", "svc")
  3. Press Enter to view that resource type

Quick Resource Switch (:) ​

k9s-style resource switching:

  1. Press : to open the command input
  2. Type the resource type (e.g., pods, deploy, svc)
  3. Press Enter to switch

Hotbar ​

The hotbar is a toggle-able sidebar on the right of the resource screens (Resource List, Resource Detail, Log Viewer — it does not appear on the Dashboard). It stores shortcuts to specific screens so you can jump between resource / context / namespace combinations without going through the selectors each time.

Each saved slot captures a resource type + context + namespace (e.g. horizontalpodautoscalers @ dev / my-namespace).

ShortcutAction
Opt+HShow / hide the hotbar
Opt+1 … Opt+9Jump to the first nine saved slots
  • Add: open the hotbar and click Add current screen to pin the screen you are on. Duplicate screens are ignored, and the containers view can't be pinned (it needs a parent pod).
  • Jump: click a slot (or press Opt+1–Opt+9) to switch the current view to that screen. It replaces where you are in the breadcrumb instead of stacking, so the depth never grows; Esc / Back then goes up one level from there.
  • Rename: hover a slot and click the pencil (✎) to give it a custom name.
  • Remove: hover a slot and click ×.

Saved slots and the open / collapsed state persist across restarts. Slots whose context is no longer in your config are dimmed.

The sidebar also has a Read-only toggle at the top. It starts from your config's readOnly value; when on, it disables mutating actions (Edit, Scale, Delete, Rolling Restart, Port-forward, Run) across all resource screens. It is a temporary, session-only switch — it never edits your config file and resets to the config value when you restart Kubby. When the hotbar is collapsed, the same toggle appears as an RO button on the rail.

View Navigation ​

Dashboard ​

The Dashboard shows multiple resource tables. Navigate between them:

ShortcutAction
TabMove to next table
Shift+TabMove to previous table
← →Navigate columns
↑ ↓Navigate rows
EnterOpen selected resource

Resource List ​

Single resource type view with full-width table:

ShortcutAction
↑ ↓Navigate resources
EnterPrimary action (varies by type)
JJump to related resources
EscGo back to Dashboard

Resource Detail ​

Detailed view of a single resource:

ShortcutAction
Y / T / JSwitch view mode
↑ ↓Scroll content
Page Up / Page DownFast scroll
EscGo back

Log Viewer ​

Streaming log view:

ShortcutAction
↑ ↓Scroll (when auto-scroll off)
AToggle auto-scroll
CCopy logs
DOpen the download menu
EscClose the download menu, then close the log viewer

Downloading logs. Pressing D (or clicking Download) opens a small menu with two choices, both saved to ~/Downloads:

  • All logs (A) — fetches the complete log for the container from the cluster (not just what is loaded on screen).
  • Visible logs (V) — saves only what is currently loaded in the viewer (the filtered lines when a text filter is active).

Tick Show logs from previous terminated container (P) to have All logs also include the previously terminated container's log (when one exists). While the menu is open Esc closes it.

Back Navigation ​

Press Esc to go back one level:

  • From Resource Detail → Resource List
  • From Log Viewer → Previous view
  • From Resource List → Dashboard
  • Closes any open modal or dialog

Refresh ​

Press Ctrl+R to refresh the current view:

  • Dashboard: Refreshes all resource tables
  • Resource List: Reloads the resource list
  • Resource Detail: Fetches latest resource state
  • Log Viewer: Restarts the log stream

Filter Input ​

Most views have a filter input for searching:

  1. Start typing to filter by name
  2. Filter applies instantly
  3. Press Esc to clear the filter
  4. Works across all visible resources

Navigation Flow Examples ​

View Pod Logs ​

Dashboard → Select Deployment → Enter (view pods) → Select Pod → L (logs)

Scale a Deployment ​

Dashboard → Select Deployment → S (scale) → Enter count → Enter (confirm)

Port Forward to a Service ​

Opt+R → type "svc" → Enter → Select Service → F (port-forward) → Configure → Enter

Jump to Related Resources ​

Select Deployment → J (jump) → Select "Pods" → View matching pods

Tips ​

Staying Oriented

The header always shows your current context, namespace, and resource type so you know where you are.

Quick Return to Dashboard

From any view, press Esc repeatedly to return to the Dashboard.

Filtering is Fast

The filter input searches as you type with no delay. Use it liberally to find resources quickly.
