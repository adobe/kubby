Actions ​

Actions are resource dependent and shown on the shortcut footer bar.

Hotbar ​

The hotbar is a toggle-able sidebar of saved screen shortcuts (resource type + context + namespace), available on all resource screens.

ShortcutAction
Opt+HShow / hide the hotbar
Opt+1 … Opt+9Jump to the first nine saved slots

See Navigation → Hotbar for adding, renaming, and removing slots. The hotbar also holds a Read-only toggle (session-only; starts from the config value) that disables mutating actions across the resource screens.

Log Viewer ​

ShortcutAction
WToggle line wrap
TToggle timestamps
AToggle auto-scroll
PToggle current / previous logs
CCopy logs
DOpen the download menu
Ctrl+RRestart the log stream
EscClose the log viewer

While the download menu (D) is open: A downloads all logs, V downloads the visible logs, P toggles including the previous terminated container, and Esc closes the menu.

Tips ​

Learn Incrementally

Start with Enter, Esc, D, and L. Add more shortcuts as you get comfortable.

Action Bar Reference

The action bar at the bottom of the screen shows available shortcuts for the current view and selection.

Modifiers

Most resource actions use single keys without modifiers. Global resource list navigation uses Opt (Alt) + key.
