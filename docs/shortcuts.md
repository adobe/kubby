# Keyboard Shortcuts

Complete reference of all keyboard shortcuts in Kubby.

## Platform Differences

Kubby displays shortcuts appropriate for your platform:

| This Guide | macOS         | Windows/Linux |
|------------|---------------|---------------|
| `Opt`      | `⌥` (Option)  | `Alt`         |
| `Ctrl`     | `⌃` (Control) | `Ctrl`        |
| `Cmd`      | `⌘` (Command) | `Ctrl`        |

## Dashboard

| Shortcut    | Action                                                                                   |
|-------------|------------------------------------------------------------------------------------------|
| `/`         | Filter by text                                                                           |
| `Esc`       | Clears filters                                                                           |
| `Tab`       | Move to next group                                                                       |
| `Shift+Tab` | Move to previous group                                                                   |
| `←`         | Navigate left in group                                                                   |
| `→`         | Navigate right in group                                                                  |
| `↑`         | Select previous row item in group                                                        |
| `↓`         | Select next row item in group                                                            |
| `Enter`     | Open selected cluster & namespace pair in last resource view (or deployments by default) |

## Resource List

### Navigation

| Shortcut       | Action                                      |
|----------------|---------------------------------------------|
| `Opt+C`        | Change context (cluster)                    |
| `Opt+N`        | Change namespace                            |
| `Opt+R` or `:` | Change resource type                        |
| `Ctrl+R`       | Refresh current view                        |
| `Esc`          | Go back / Cancel / Close modal              |
| `↑`            | Select previous resource                    |
| `↓`            | Select next resource                        |
| `Enter`        | Primary action (context-dependent)          |
| `J`            | Jump to related resources                   |
| `A`            | Open AI assistant (if configured)           |
| `Esc`          | Clear filters, then return to previous view |

### Actions

Actions are resource dependent and shown on the shortcut footer bar.

## Modals & Dialogs

| Shortcut | Action         |
|----------|----------------|
| `Enter`  | Confirm action |
| `Esc`    | Cancel / Close |

## Scrolling

| Shortcut    | Action               |
|-------------|----------------------|
| `↑` `↓`     | Scroll line by line  |
| `Page Up`   | Scroll up one page   |
| `Page Down` | Scroll down one page |
| `Home`      | Scroll to top        |
| `End`       | Scroll to bottom     |

## Tips

::: tip Learn Incrementally
Start with `Enter`, `Esc`, `D`, and `L`. Add more shortcuts as you get comfortable.
:::

::: tip Action Bar Reference
The action bar at the bottom of the screen shows available shortcuts for the current view and selection.
:::

::: tip Modifiers
Most resource actions use single keys without modifiers. Global resource list navigation uses `Opt` (Alt) + key.
:::
